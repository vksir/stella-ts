# 外观转向纸感工作台，放弃 DSH 像素复刻

> **Status: 已采纳（accepted）**。取代 [ADR-0003](0003-react-frontend-kernel.md) 中「观感层与 dsh 逐项对齐」的验收基准；渲染内核（React 18 + 每 key 订阅 + 增量 Markdown）不变。

Stella 的 Web 外观从 DeepSeek Harness（dsh）复刻改为「纸感工作台」：纸白 / 墨色 / 苔绿 / 暖沙的低饱和配色，Instrument Serif + Inter 的编辑感排版，三栏布局（侧栏 / 对话 / 详情栏）与 3% 纸纹。蓝本是 `D:/Workspace/deepseek-max` 的 Aria 演示（浅色、纸感、克制的多会话 Agent 工作台），本 ADR 记录为什么换、换到什么程度、以及刻意不做什么。

## 为什么换

dsh 复刻在 ADR-0003 里已经完成并验收（观感 9.3/10），但它把 Stella 的品牌表达锁在别人的产品语言里：蓝色主色、Montserrat 字标、两栏 + 对话/轨迹 Tab、DSH 特有的控件密度。Stella 的定位是「万用日常型 Agent」，不是编程工具，也不是 dsh 的替代品；继续像素级复刻会让用户第一眼把它当成另一个 DeepSeek Harness。纸感工作台提供的是另一套气质：安静、可读、像一本摊开的工作笔记，更适合日常读写与长对话。

## Decision

- **三栏是默认形态**：286px 侧栏 / 780px 对话 / 318px 详情栏；<1280px 详情栏变成右侧抽屉，<900px 侧栏变成抽屉。侧栏收起 rail（56px）保留，因为它是已上线的功能，不因换皮丢掉。
- **详情栏承载真实数据**：预设卡、上下文用量、工具轨迹（最近 6 次 + 「查看全部」弹层）、会话信息。轨迹不再是头部 Tab；`GLOSSARY` 的「轨迹视图」定义随之更新。
- **浅色是验收基准，深色是派生**：同一套 token 输出的夜间纸感色板，保留已有的「浅色 / 深色 / 跟随系统」三态；不为了保真删掉已上线功能。
- **字体自托管拉丁、中文走系统栈**：Instrument Serif（标题西文）+ Inter（正文西文）以 woff2 落在 `web/assets/fonts`；中文衬线用 Noto Serif SC / Songti SC / SimSun，不引入巨型中文字体，不依赖 Google Fonts。
- **功能语义不动**：预设创建时锁定（ADR-0002）、排队 / 插话、续跑、引用、压缩通知、缺口补齐、技能、模型收藏、斜杠指令全部保留，只换外观与入口。
- **不摆假按钮**：置顶、重命名、清空、未读、跨会话并行、附件、重新生成、工具来源 chips 一律不做——它们要么缺服务端数据，要么会改变「会话标题 / 预设 / 提交」的既有语义。Aria 的 agent card 映射为**预设卡**，不引入 persona / 智能体切换。（「思考过程折叠」已从本清单移出，由 [ADR-0007](0007-thinking-content-in-chat.md) 承接。）
- **会话分组要有真实口径**：服务端在 `ConversationMeta` 补 `updatedAt`（提交与回答落定时更新），列表按它分「今天 / 昨天 / 更早」；旧数据回落 `createdAt`。

## Considered Options

- **只换 CSS 皮肤，保留两栏与轨迹 Tab**：改动最小，但拿不到纸感工作台的三栏气质，最终只是「蓝色换成苔绿」的半成品，故放弃。
- **继续 DSH 像素级复刻**：观感已验收，但与 Stella 的品牌定位冲突，且把产品语言交给别人的设计系统，故放弃。
- **全量照搬 Aria 的功能面**：Aria 是演示，置顶/未读/并行/附件/重新生成背后没有真实数据；照搬会得到一排假按钮，故只取有真实支撑的部分。

## Consequences

- 详情栏在 1280–1440px 会挤压对话列；这是三栏布局的固有代价，用 780px 的对话上限和抽屉断点控制。
- 深色不再是 DSH 蓝，而是夜间纸感；若未来要回到高对比深色，需要重新设计一套 token，而不是改几个颜色。
- 旧会话的 `preset` 元数据可能为 null：详情栏显示「默认预设」并说明能力已锁定在会话里，不猜测、不回填。
- 验收从「与 dsh 逐项测量」改为「与 Aria 蓝本对照 1440 / 768 / 390 截图 + 浏览器走查关键路径」；`README` 与 `GLOSSARY` 同步，不再声称「与 dsh 逐项对齐」。
